# LUDIA NAIL v1.5 — Salon OS First + Instant ART Editor

## Product hierarchy correction
- LUDIA NAIL is positioned first as an Ahasoft-replacement salon operating system.
- Primary mobile navigation simplified to: Today / Booking / Customers / More.
- ART STUDIO removed from the primary navigation.
- ART STUDIO now lives under More > Add-on as an optional premium creation module.
- Today screen prioritizes booking flow, customers, memberships, and sales instead of art creation.

## LUDIA ART STUDIO — Instant Edit
- Finger photos are direct touch targets.
- Tap one or multiple fingers, then tap a quick modification chip.
- Changes preview immediately without waiting for a separate apply step.
- Supported instant visual directions include lighter, deeper, simple, parts reduction, accent, stronger magnet, aurora, Seongsu, Gangnam, soft/clean, glam, executable/easy, price-down, monthly-art, and omakase modes.
- Service time and recommended price recalculate from current edit state.
- Editing history can still be committed for reuse and saving.

## Final multi-angle preview
- Added a draggable perspective final preview.
- Drag horizontally/vertically to inspect balance from different angles.
- Added front / left 30° / right 30° / top 25° quick-angle buttons.
- Finger-specific edits are reflected in the multi-angle preview.
