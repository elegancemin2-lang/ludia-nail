# LUDIA NAIL v1.9 — Reference-led Apple-grade Salon OS Shell

## Structure
- Main shell stays Today / Booking / Customers / More.
- Today is no longer a dashboard grid: it is a large-title mobile agenda with the next appointment, glance metrics, today schedule and grouped alerts.
- More is rebuilt as grouped settings rows rather than a card gallery.
- ART STUDIO remains an add-on under More.

## Calendar
- Preserves staff-by-time scheduling.
- Refines the 7-day selector, Today action, staff chips, current-time line and appointment blocks into one neutral iOS-like system.
- Empty time slots remain directly tappable for quick booking.

## Visual system
- Neutral system-gray surfaces, black text and one iOS-blue interaction accent.
- Removed most beige/rose UI decoration from the Salon OS shell.
- Reworked bottom navigation with simple line icons and tint-only active state.
- Customer area now reads as a contact list, not a CRM dashboard.

## Reliability
- Restored full app.js, styles.css and sw.js after an empty-file GitHub regression.
- Service-worker cache bumped to v1.9.
- JavaScript syntax check passed locally.
