LUDIA NAIL · PC 연결

로그인하고, 예약 연결

최초 한 번 예약 내용을 확인하면 다음부터 저장한 설정으로 시작합니다.

연결 설정을 불러오는 중이에요.

1

네이버에 직접 로그인

전용 네이버 창을 열고 매장의 예약관리 목록으로 이동하세요. 비밀번호·보안문자·2단계 인증은 네이버에서 직접 입력합니다.

아직 창을 열지 않았어요.

2

예약 내용 한 번 확인

예약관리에서 전체 상태 · 취소 포함 목록을 여세요. 실제 표에 예약번호·일시·상태 제목이 있으면 자동으로 확인합니다.

자동 확인이 안 될 때 직접 선택

아래 버튼을 누른 뒤 네이버 창에서 해당 항목을 클릭하세요. 한 줄 전체는 마우스를 올리고 ↑로 영역을 넓힌 뒤 Enter로 선택합니다.

고객·시술·담당자 등 추가 항목

화면에서 각각 확인되는 항목만 선택합니다. 사진 첨부는 아직 연결하지 않습니다.

선택 영역 직접 확인·수정

네이버 화면을 실제로 확인한 선택 영역만 사용하세요. 빈 항목을 임의로 추정하지 않습니다.

취소가 다른 목록에 있을 때

먼저 위 예약 미리보기를 확인하세요. 네이버 창에서 같은 매장의 취소 목록으로 이동한 뒤 아래 버튼으로 추가합니다. 같은 형식의 예약이 한 건 이상 보여야 확인할 수 있어요.

기본 목록만 연결합니다. 설정을 다시 저장할 때는 추가 목록도 재확인하세요.

현재 화면의 조회 기간·페이지에 렌더링된 예약만 확인합니다. 다른 매장·조회 기간으로 이동하면 다시 확인합니다. 목록에서 사라졌다는 이유로 취소 처리하지 않습니다.

3

예약 전달 방식

연결 프로그램이 여는 LUDIA 창에 바로 저장합니다. 폴더 선택은 필요 없어요. 기존 일반 Chrome·휴대폰의 데이터와는 별도입니다.

검사만으로 예약을 저장하거나 연결 상태를 바꾸지 않습니다. 서버 준비가 끝나야 이 방식으로 저장할 수 있어요. PC 키는 예약 조회·관리자 권한을 주지 않습니다.

서버 예약표의 담당자·시술 연결은 매장에 등록된 매핑 기준을 사용합니다. 매핑이 없으면 미지정으로 표시하며 선택한 텍스트만으로 직원을 임의 배정하지 않습니다.

저장과 실행 따로 하기

저장 후 실행합니다. 연결됨 표시는 정상 수집과 저장에 성공한 뒤 나타납니다.

이 설정 화면은 이 PC에서만 열립니다. 로그인 쿠키와 설정 파일은 PC 밖으로 업로드하지 마세요.

초기 연결은 네이버 → LUDIA입니다. LUDIA에서 만든 예약이 네이버 빈 시간을 자동으로 막지는 않습니다.
